Logos used by the app. Add them with exactly these names:

- `compass_logo.svg`, `.png` or `.webp`
  Project Compass logo, shown at the top of the front (Connect) page and
  used as the browser tab icon. About 48 px tall on screen, so a PNG at
  least 200 px tall with a transparent background looks sharp.

- `snap_logo.svg`, `.png` or `.webp`
  Snap Analytics logo, shown in the bottom-right corner of every page.
  About 30 px tall on screen; use a transparent background.

SVG is best for both, as it stays sharp at any size. If a file is missing,
the app shows the name as text instead.

Optional: `compass_icon.png` (a square mark) for the browser tab icon.
